# SENTRY · whole-body robotics lab

**[Drive it live →](https://sentry-robotics-lab.vercel.app)**

![SENTRY in MuJoCo](public/sentry/poster.jpg)

A 12-actuator, free-floating quadruped walks under manual control or navigates around crates. The live browser lab runs real MuJoCo WebAssembly physics with a torque-driven crawl, A* routing, and contact telemetry. A separate recorded experiment compares whole-body stance control against joint PD under two physical pushes.

```sh
npm install
npm run dev
```

Open **http://127.0.0.1:5173/sentry.html**. Hold **WASD / Q / E**, or choose **Around the crates** to navigate. No Python server is needed. See the **[live controller and navigation guide](simulation/LIVE.md)** for controls, architecture, tests, and deployment.

Choose **Recorded experiment** to switch between **Whole-body** and **Joint PD**, scrub to either push, and inspect contact loads, body tilt, and height tracking. The following numbers describe that stationary experiment only. Its checked-in videos and logs were generated by the Python experiment.

| Nominal 14-second trial | Whole-body | Joint PD |
| --- | ---: | ---: |
| RMS body tilt | 0.182° | 0.959° |
| Peak body tilt | 0.983° | 2.493° |
| Body-height RMSE | 1.50 mm | 14.62 mm |
| Recovery after first / second push | 0.19 / 0.19 s | Not recovered / 0.73 s |

Metrics exclude the first second of settling. Recovery requires 0.5 s continuously below all documented error thresholds, before the next push. These are deterministic simulated results, not statistical reliability estimates.

The five-case sweep includes a failure: the whole-body controller falls with a 4 kg payload, friction 0.25, and 2.5× pushes. It cannot take a recovery step. The joint-PD baseline stays upright but slides about 0.92 m and also fails the mission criteria.
